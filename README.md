# muskanportfolio.github.io

Portfolio site for Muskan Chauhan — Unity Game Developer.

## Publish on GitHub Pages
1. On GitHub, open the repository named exactly `<your-username>.github.io`
   (for the address muskanportfolio.github.io, the GitHub account must be `muskanportfolio`).
2. Click **Add file → Upload files** and drag in everything from this folder
   (`index.html`, `.nojekyll`, `README.md` and the `assets` folder), then **Commit changes**.
3. Go to **Settings → Pages**, set **Source: Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. After a minute or two the site is live at `https://<your-username>.github.io`.

## Updating
- Text lives in `index.html` — search for the game name to edit its section.
- Replace a clip by overwriting the file in `assets/clips/` with the same name.
- Replace the resume by overwriting `assets/Muskan_Chauhan_Resume.pdf`.
