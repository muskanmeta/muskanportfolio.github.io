Hungry Shadow

2D action brawler for BattleBucks, Android

Solo developer: gameplay programming, combat and enemy AI, game feel

  • Combat runs on a state machine covering standing, crouch, air and weapon combos. An input buffer drops stale inputs, so fast taps never fire late or the wrong way.
  • 8 enemy types built on one shared AI base, with knockback, knock-up and air juggles, plus weapon drops the player can catch and throw.
  • Hit-stop, combo-synced camera shake, pooled VFX and custom shaders, with Spine animation blended to the knockback.
  • A steady 80–90 FPS on mid-range Android: pooling, preloaded audio and shader variants, no per-frame allocations.
  • Unity (C#)
  • Spine 2D
  • Feel
  • Addressables
  • Custom shaders

Shadow Jump

2D arcade platformer for BattleBucks, Android

Gameplay mechanics, game feel and shaders

  • 15+ custom Feel feedbacks for jump, double jump, landing, dash, trail and death. Landings scale with how hard the player hits the ground.
  • A URP sprite shader that leans the character from the feet up on spring motion. It uses MaterialPropertyBlocks, so sprites still batch.
  • Rebuilt the player animation as an event-driven system: gameplay never references effects directly, so feedback can be retuned without risking gameplay bugs.
  • Reworked the double jump, swapped physics colliders for a custom capsule check for fairer sawblade hits, and added a fixed-aspect camera.
  • Unity (C#)
  • Feel
  • URP shaders
  • Animator

Grim

4-player online arena shooter, co-developed, live on Google Play

Gameplay programming, game feel and VFX, and the full game UI

  • Weapons that can be picked up and thrown (pistol, assault rifle, shotgun, sniper, grenade) on one shared weapon base, with recoil and aim assist. The server decides every grab, so two players never take the same weapon.
  • Combat feedback built with Feel: hit-stop on kills, camera punches, squash and stretch, and touch feedback on the combat buttons. VFX come from a pooled, capped system, so busy 4-player fights stay smooth on phones.
  • Designed and built the full menu flow: home hub, hero gallery and mastery, daily rewards, chests, missions, friends and chat. Each screen talks to the backend through an interface, so services can be swapped without touching the UI.
  • Co-developed with one other developer, each owning separate modules, integrated through feature branches and code reviews.
  • Unity 6 (C#)
  • Photon Fusion
  • Unity Gaming Services
  • Feel
  • UI

How I work

Feel first

I get the moment-to-moment feel right early: hit-stop, squash and stretch, camera and sound. Then I tune it until it reads well on a small screen.

Fast on real phones

Pooling, batching and allocation-free updates, checked in the profiler on mid-range Android rather than in the editor.

AI in the loop, my judgment

I use AI tools every day to prototype faster, dig into analytics and pick up new tools. I check what they produce in the engine and the profiler before it ships.

Decide with data

Plan the events before launch, read retention and level funnels after it, and change one thing at a time.
